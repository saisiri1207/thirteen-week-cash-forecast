# 13-week cash forecast

Weekly cash view for a fictional company (**Northline Consumer Products**).

**File to open:** `Northline_13_Week_Cash_Forecast.xlsx`

## What you will see

- Starting cash
- Customer receipts by week
- Payroll, vendors, tax, and other disbursements
- Ending cash each week
- A short runway note if cash falls

Yellow cells = inputs. Black = formulas.

## Why this belongs on an FP&A profile

A monthly P&L can look fine while cash is tight. This file is the weekly conversation with treasury and operations.

All numbers are made up.
